Entry for the [make.fun bounty](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214?utm_source=github&utm_medium=readme&utm_campaign=u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214): write the funniest one-line excuse a robot vacuum gives for missing a spot, 140 characters at most. An AI judge picks the winner, who takes the $2 reward.

## The entry

> My LiDAR classified that corner as a wall, and after three years of bumping into it, I've decided it's right.

The vacuum doesn't deny missing the spot — it blames its own sensors, then admits it has been gaslit by its own map for three years and has finally sided with the faulty data. A machine that has started to believe its own faulty map is the most robot excuse possible.

## What this does

`main.py` (Python 3.13, stdlib only, deterministic — no network, clock, or randomness) validates the entry (single line, 1–140 characters), prints it to stdout, and also writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set, falling back to `./output/entry.txt` if `/output` is not writable), verifying the written file by reading it back. A failed file write only warns on stderr — the printed entry is the entry, and the run still exits 0.

## How to run

```bash
python3 main.py
```

Exits 0 on success. The entry text is printed to stdout and written to `entry.txt` in the output directory.
